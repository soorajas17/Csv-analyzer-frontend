# CSV Analyzer Frontend

# Tech Stack
- React.js
- React Bootstrap
- Axios
- Chart.js

# Features
- Upload CSV files
- Display dataset in table format
- Select column to view statistics
- Display histogram for numeric columns

# Setup & Run Instructions
- Clone the repository
  ```bash
git clone https://github.com/soorajas17/Csv-analyzer-frontend.git
cd Csv-analyzer-frontend
- Install dependencies
  npm install
- Start the application
  npm start
- Application runs on
  http://localhost:3000

# Backend Integration
